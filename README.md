# 3D-Printed Mount Design for a Weather Monitoring System

> **My role:** 3D design of the hardware mount  
> **CAD software:** Autodesk Fusion 360  
> **3D printer:** Bambu Lab P1S

## Project Overview

This project involves the development of a weather monitoring system. My contribution was the **mechanical design of the mount used to house and arrange the project's hardware**.

I designed the mount in **Autodesk Fusion 360** and fabricated the design using a **Bambu Lab P1S 3D printer**.

My responsibility was limited to the 3D modelling and mount design. The other project activities, including electronics, firmware, sensor interfacing, and system testing, were carried out by other team members.

## My Contribution

- Created the 3D model of the hardware mount using Autodesk Fusion 360.
- Designed the enclosure geometry and internal space to accommodate the project hardware.
- Added openings to the mount where required for hardware access.
- Prepared the CAD design for 3D printing.
- Printed the designed mount using a Bambu Lab P1S 3D printer.
